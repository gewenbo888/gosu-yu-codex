# The Gosu Yu Codex · 戈苏御宇宙典

A 100,000-word original universe expanded from the **Suyu / 戈苏御** mythology ("the Last Name").
A single bilingual (English / 中文) illuminated codex of twenty volumes, written with an
*entropy-maximizing* method — every sentence introduces a new concept, so novelty density rises
continuously while the world stays internally consistent.

The twenty volumes span cosmogony, cosmology, historical epochs, civilizations, factions, governance,
technologies, currencies, ecosystems, professions, rituals, languages, artifacts, architecture,
philosophies, conflicts, mysteries, future timelines, geography, and an expanded codex of beings —
all built on the canonical spine of the Five Worlds, the Aperture, the Long Broadcast, and the Gate.

- **Scale:** ~101,000 English words + ~167,000 Chinese characters across 20 volumes / 225 sections.
- **Diegetic frame:** compiled by the *Concordance of the Aperture / 隙之集会*.
